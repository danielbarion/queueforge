# Bench smoke 2026-09-28

This is not the reference run in `docs/PERFORMANCE.md`. The window is 5 seconds plus 1 second of warmup, TLS is off, and group commit is 100 ms. The hypothesis table stays a hypothesis until the same shapes are run for 30 seconds on the reference host (8 vCPU, 32 GB, NVMe).

| | |
|---|---|
| Commit | `a9153b3` plus the uncommitted runtime changes in this working tree |
| Host | macOS 26.6.2, Apple M4 Max, 16 cores, 128 GB (`sysctl hw.memsize`) |
| Broker RAM probe | 8 GB (`total_ram_bytes=8589934592` at startup) |
| Binary | `cargo build --release` of `queueforge` and `queueforge-bench` |
| Listeners | AMQP `127.0.0.1:25672`, management `127.0.0.1:35672` |
| Command | `queueforge-bench --shape all --duration-secs 5 --warmup-secs 1` |

## Measured

| Shape | Ingress | Consumed | Publish p99 | E2E p99 | Notes |
|---|---|---|---|---|---|
| A | 23,648 msg/s | 0 | 24.8 µs | none | Consumer got `NOT_FOUND` after `queue.delete` of a missing queue closed the channel. Publishes were unroutable. |
| B | 169,429 msg/s | 21,742 msg/s | 688 µs | 5.22 s | Ingress cleared the 100k hypothesis on this short window. 31 consume errors: duplicate consumer session ids across connections. |
| C | 8,928 msg/s | 89,208 msg/s | 57.9 µs | 270 ms | Fanout ingress missed 50k. Consume count is higher than ingress because each publish is delivered to 10 queues. |
| D | 10 msg/s | 10 msg/s | 107 ms | 107 ms | Persistent confirms tracked the 100 ms group-commit interval. Throughput is not meaningful at a 5 second window with that fsync cadence. |
| E | 171,012 msg/s | 26,677 msg/s | 337 µs | 5.10 s | Management list p99 was 13.5 ms over 97 calls (budget 50 ms). Same session-id consume errors as B. |

Do not treat the ingress rates as the broker's ceiling. Shape A did not consume, shapes B and E dropped consumers, and the window is one sixth of the procedure in `docs/PERFORMANCE.md`.
